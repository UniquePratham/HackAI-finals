# HackAI-finals

HackAI finals build - full-stack application with a Node backend and MongoDB.

Full-stack hackathon build. The backend lives in `Backend/` and expects `MONGODB_URI` in the environment.

## Stack

- JavaScript
- Next.js
- Chakra UI
- MongoDB
- NextAuth
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```
